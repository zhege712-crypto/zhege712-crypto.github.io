# 伞 / umbrella

## Platform
Web: personal portfolio, existing static GitHub Pages site.

## Purpose and audience
Visitors browse the owner's photography, videos, writing and interest archives. The homepage leads into the portfolio and recent updates.

## Confirmed direction
The homepage uses the site's existing light portfolio design, with the introductory poem, clear featured photographs and recent updates. Other pages retain their normal backgrounds. Music starts only after explicit activation.

## Stack and constraints
Existing HTML/CSS/JavaScript and JSON data, Vite local development, GitHub Pages hosting. The public website must work without a backend or external runtime CDN. Preserve all page functions and existing uncommitted work. Mobile scrolling, keyboard navigation and reduced motion must work.

## Scope
The wheat-field design has been removed. Public archives, admin and test pages keep their own backgrounds and functions.
